What changed vs. the current simulator

Current simulatorCorrected workflow
/spec runs once globally, splits text into features /spec runs globally for top-level SPEC.md and again per feature
Lane starts at /plan Lane starts at /spec (per-feature), then /plan
/interview-me is a slash command with 3 canned questions interview-me is a skill triggered by intent gaps; idea-refine added as a peer
/build → /test → /review (rigidly linear) /build ↔ verify loop, then Review phase
Review is one step ("code-reviewer persona") Review = /review + /code-simplify + security + performance
Adding a new feature skips /interview-me and /spec Adding a new feature re-enters at per-feature /spec
Only loop is NO-GO → Phase D → re-/ship Loops at Build↔Verify and NO-GO → Build (fixes re-enter the build pipe)
